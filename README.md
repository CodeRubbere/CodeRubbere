### HBC+ · Home Battery Control Plus

Phase-aware home battery control for Home Assistant and Node-RED: Marstek Venus E batteries, a phase guard per phase, dynamic prices and peak shaving, without vendor lock-in.

[Repository](https://github.com/CodeRubbere/HASS-HBC-Plus) · [User guide](https://github.com/CodeRubbere/HASS-HBC-Plus/blob/main/docs/user-guide.en.md) · [Gebruikershandleiding](https://github.com/CodeRubbere/HASS-HBC-Plus/blob/main/docs/gebruikershandleiding.nl.md)

HBC+ builds on HBC by [CodeBob](https://github.com/gitcodebob).
